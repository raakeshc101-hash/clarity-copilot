# Clarity Copilot

Clarity Copilot is an AI-powered onboarding decision-support system designed to reduce ambiguity for early-career employees.

## What it does

- Diagnoses onboarding confusion using I-O psychology principles
- Identifies primary blocker to action
- Routes employees to the right person (not always the manager)
- Generates targeted, first-person questions
- Provides ready-to-use communication scripts
- Tracks patterns using anonymous user data

## Key Features

- 7-category clarity taxonomy
- Behavioral barrier detection
- Retention risk signaling
- Intelligent routing logic
- User history tracking
- Admin dashboard for aggregate insights

## Tech Stack

- Python (Flask)
- OpenAI API
- SQLite (prototype storage)
- HTML/CSS
